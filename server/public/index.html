        Notificações

        Sobre os dados

        Forex, cripto e ações ao vivo vêm da API da Twelve Data (plano gratuito com chave pessoal; ações dos EUA só durante o pregão, cripto 24 horas). Pares OTC das corretoras são preços sintéticos e não existem em API pública; no modo OTC do ZigZag o robô analisa tendência e lateralização sobre o preço real.

        Janela flutuante: no Chrome e no Edge do computador abre uma mini janela que fica por cima das outras. No Android (Chrome) usa o modo imagem sobre imagem. No iPhone pode não funcionar; nesse caso use as notificações.

        O payout de cada par é informado por você. Gale (martingale) dobra a exposição a cada perda: use com cautela.

        Sinais são educacionais. O robô nunca envia ordens.

        Configurações

        Conta e dados

        A chave é gratuita: crie uma conta em twelvedata.com e copie a API key do painel.
        IQ Option
        Com a IQ Option conectada, os ativos de cada robô (inclusive os OTC) e os gráficos passam a ser os da própria IQ Option.
        O login fica só no servidor (variáveis IQ_EMAIL e IQ_PASSWORD) e a conta é usada no modo PRÁTICA. O robô só lê velas e payout: nunca compra nem vende.
        Use se no seu MT o EURUSD aparece como EURUSD.m ou EURUSDm. A chave e a conta da API2Trade ficam só no servidor (variáveis API2TRADE_API_KEY e API2TRADE_ACCOUNT_ID).
